## 재현 — 실제 파일 없이 머리 이름만 바꿔 가며

`L.detectColumns([머리, 자료])` 로 소재 칸 이름을 바꿔 넣으니 **한 줄 머리에서도** 증상이 났습니다(두 줄 머리만의 문제가 아니었음).

| 머리(소재 칸) | 고치기 전 | 고친 뒤 |
|---|---|---|
| `소재 \| 규격` · `소재 \| 소재규격` · `소재 \| 소재 lot \| 규격` | 메이커 없음 · 규격 = 「소재」 칸(회사 이름) · 「규격」은 「한 번 더 보입니다」로 버림 → **규격 탭에 회사 이름, 메이커 탭 없음 = 보고된 증상** | 메이커 = 「소재」, 규격 = 「규격」 |
| `규격 \| 소재` (순서 바꿈) | 메이커 없음 | 제자리 |
| `소재명 \| 소재 사양` · `소재 사양 \| 소재명` | 메이커 없음 | 제자리 |
| `원소재 \| 제조사` | 규격 없음 | 원소재 = 규격, 제조사 = 메이커 |
| `자재 \| 공급업체` | 둘 다 없음 | 자재 = 규격, 공급업체 = 메이커 |
| `공급사 \| 재질` | (우연히 맞음) | 제자리 |
| `Material \| Spec` · `Supplier \| Material` · `Maker \| Grade` | 일부 없음 | 제자리 |
| 두 줄 병합 「소재」 아래 「메이커」「규격」 | 맞음(오후 판) | 맞음 |
| `소재 \| 소재 메이커 \| 소재규격` | 「소재」가 규격을 차지, 「소재규격」 버림 | 구체 이름이 이김(「소재」는 연결 안 하고 알림) |
| `재질 \| 소재`(둘 다 애매, 값으로만 가를 수 있음) | 「재질」 = 규격, 「소재」 버림 | 아래 값 모양으로 |
| `메이커 \| 규격` 인데 값이 뒤바뀜 | 그대로 뒤바뀜, 알림 없음 | 머리대로 두고 알림 + 「두 칸 바꾸기」 |

**원인**: 「소재」「재질」은 소재규격 별칭, 「제조사」「공급사」는 메이커 별칭이었고, 별칭은 「앞 칸부터, FIELDS 순서상 먼저 맞는 항목」이 차지했습니다. 애매한 이름이 먼저 자리를 잡으면 뒤의 분명한 이름은 중복으로 버려졌습니다.

## 왜 이렇게 했나

- **원인을 「안 바뀌었다」로 끝내지 않았습니다.** 사용자가 바뀌었다고 느낀 데는 이유가 있어서, 샘플 구조(규격 = 금형)와 실제 파일에서 날 수 있는 모양(두 줄 병합 머리)을 따로 따져 봤습니다. 두 번째는 재현되는 결함이라 고쳤고, 첫 번째는 데이터가 그렇게 생긴 것이라 화면에서 알려 주는 쪽으로 했습니다.
- **두 줄 머리 판단**: 아랫줄에 숫자·날짜가 하나라도 있으면 자료 줄로 보고 붙이지 않습니다(한 줄 머리 작업일보는 그대로). 붙일 때는 「윗줄 + 아랫줄」을 먼저 맞추고(「불량」+「수량」 = 불량수량), 안 맞으면 아랫줄만 봅니다(「불량」+「주름」 → 주름).
- **「설정압」은 지금처럼 압력 값**으로 읽습니다. 현장 작업일보는 설정값을 적는 곳이 많고(수강생 답: 지금 시트 값은 기준 값), 1단계 검사도 그렇게 되어 있습니다. 「기준·표준」이 붙은 칸만 기준 칸으로 보고, 「설정」「실제」 두 칸이 함께 있을 때만 설정을 기준으로 돌립니다.
- **기준 값 그대로인 작업일보도 돌게** 했습니다. 지금은 차이가 모두 0 이라 전파가 0 건이고, 화면·보고서·프롬프트에 「기준(설정) 값을 적은 것으로 보임」을 적습니다. 실제 값이 들어오면 같은 화면이 그대로 저하를 보여 줍니다.
- **허용 폭과 같은 만큼 낮은 것은 저하가 아님**(「기준 − 허용」보다 낮을 때만). 허용을 비우면 0 이라 조금만 낮아도 올라가니, 화면에 그렇게 적었습니다.
- **샘플 난수 순서 유지**: 로트·저하를 날짜로 정해 난수를 더 쓰지 않아서, 로트 A-2607·저하 기간 밖의 행은 값이 그대로입니다. 1차 검사 35개는 칸 위치(lot 칸 추가)·보고서 절 번호·로트 가리기만 고치고 패턴 검사는 그대로 통과합니다. 전체 불량률은 5.26% → 5.49%(로트·주름을 심은 만큼).
- **전파는 글·엑셀까지**: 이 도구는 서버가 없고 메신저 연결도 없어, 복사해 보내는 글로 만들었습니다. 자동 알림은 Make(기획서 7장) 2단계 후보입니다.

- **샘플에서 찾은 것**(전체 불량률 5.26%): 1위 「겨울 × 소재사B」 9.83%(기대보다 2,247개 많음), 쿠션 압력 70~75 9.62%, 65~70 9.54%, 「겨울 × 금형 DIE-B01」 8.6%. DIE-B01 은 보수 후 누적 0~1만 5.1% → 3~4만 8.5%로 오르고, 보수 4번 모두 보수 뒤 30일 불량률이 내려갔습니다(12월 보수는 겨울 소재사B 영향으로 7.6% → 7.3%로 조금만). Main 압력 240~250 도 걸렸지만 그 작업의 96%가 DIE-B01 이라 「겹침」이 붙습니다(대조군이 걸린 이유가 화면에 드러남).

## 왜 이렇게 했나

- **불량률은 늘 작업량 가중**(불량 합계 ÷ 작업수량 합계)입니다. 제출 글도 「작업량 대비 불량률」이고, 하루 불량률의 평균은 작업량이 적은 날을 지나치게 크게 셉니다. 검사에서 두 값이 실제로 다른 표를 써서, 평균으로 바꾸면 실패하게 했습니다.
- **「불량이 몰린 조건」은 거름망**입니다. 압력 구간·계절·메이커 같은 조건을 수십 개 훑으면 우연히 높은 것이 나오므로 ① 표본(작업 3,000개·5행) ② 전체의 1.3배 ③ 윌슨 95% 하한도 전체보다 높음, 세 겹으로 거릅니다. 두 조건 조합은 「각 조건 하나일 때보다 1.2배 이상, 하한도 더 높을 때」만 보여 줘서, 한 조건으로 설명되는 조합(예: 쿠션 70~75 × 아무 금형)이 목록을 채우지 않게 했습니다. 원인 판정이 아니라는 문구를 화면·보고서·프롬프트에 함께 둡니다.
- **겹침 표시**: 샘플에서 관계없게 만든 Main 압력이 걸렸는데, 그 압력 구간이 거의 한 금형(DIE-B01)의 작업이었습니다. 실제 공장에서도 금형·모델마다 압력 설정이 다르니 같은 일이 생깁니다. 그래서 조건의 작업량 70% 이상이 한 금형·메이커·작업자·계절에 몰려 있으면 「겹침」을 붙입니다.
- **금형·모델·규격이 1:1 이면** 같은 행 묶음이 이름만 바꿔 세 번 나와서, 행 묶음이 같으면 첫 것만 두고 나머지는 「같은 작업 묶음」으로 적습니다.
- **보수 시점은 「예측」이 아니라 참고값**만 냅니다(강사 요청 댓글: 이력이 쌓인 뒤). 금형마다 보수 후 누적 작업량 구간별 불량률을 내고, 보수 직후보다 1.3배 이상 높아져 그 뒤로도 내려오지 않는 첫 구간을 「참고」로 보여 줍니다. 처음에는 「목표 2%를 넘는 구간」으로 했다가, 바탕 불량률이 이미 2%를 넘어 모든 금형이 0개부터 걸려서 바꿨습니다.
- **이름 가리기 범위**: 금형·모델·소재 메이커·작업자·로트를 「금형1」처럼 바꿉니다. 소재규격(예: STS430 1.2t)과 압력 값·수량은 회사를 알아볼 정보가 아니고 분석에 필요해서 그대로 둡니다. 비고 같은 자유 글은 프롬프트에 넣지 않습니다.
- **정상 압력 범위는 비워 둠**(10장 ⑤ 확인 전). 비어 있으면 같은 폭 구간으로만 보고, 넣으면 아래·안·위로도 봅니다. 샘플에만 가상 범위를 넣었고 배너에 적었습니다.
