① 직무·소속 : (회사명 생략) / 구매팀
② 해결하고 싶은 현안 1건 : Deep drawing press 금형 작업 제품 불량 최소화(사유 : 높은 단가의 수입 자재로 불량률을 최소화하여 원가 손실을 줄이고자 함. 현재 불량률이 약 5% 수준으로 2% 수준으로 낮추는 것으로 목표 설정)
③ 보유 데이터 유형 : 해당 공정 작업일보 현황(excel)으로 세부 데이터 내용으로는 작업일자 / 작업자 / Hydro press main 압력 / 쿠션 압력 / 금형 / 작업모델 / 소재 메이커 /소재규격 / 작업수량 / 불량수량 등의 데이터를 수집할 수 있음
④ 기대 산출물 : 1. 작업 일별/월별 작업량 대비 불량률 분석표 2. 금형/소재별 작업량 대비 불량률 분석표. 해당 데이터 수집 집계 분석으로 제품 불량(Crack)의 원인을 계절별 4M에 근거해서 추측할 수 있는 데이터 산출되어 불량률을 낮추는데 활용할 것으로 판단됨(소재 문제/프레스 압력 문제/금형 보수 시점 예측으로 사전 보수 등)

자료 요청:

1. 작업일보 엑셀 견본(최근 6개월~1년)
