## 7. 한계와 남은 일

- 업무 자료(작업일보 · 이력 · 작업표준)는 아직 팀 공유 DB 가 아니라 이 브라우저에 저장합니다. JSON 백업으로 옮깁니다.
- 실제 작업일보 견본을 아직 받지 않아 샘플은 제출 글 항목대로 만든 가상 값입니다. 정상 압력 범위 · 허용 폭은 확인 전입니다.
- 작업일보 압력 값이 기준 값 그대로면 기준 대비 실제 비교는 「기준 값을 적은 것」으로 알립니다 — 실제 압력(act) 값은 나중에 연결합니다.
- 금형 보수 시점 예측과 전파 자동 알림은 하지 않습니다.
- 로그인 뒤 화면(게시판 · 관리 · 첫 화면 고르기)은 가짜 Supabase 로 화면 흐름을, 로컬 PostgreSQL 과 과정용 프로젝트에서 SQL 권한을 확인했습니다. 실제 계정으로 로그인해 누르는 확인은 요청자 몫입니다.
- 독립 운영까지 남은 것: 본인 Supabase 프로젝트에 auth.sql · board.sql · site.sql 실행 → js/auth-config.js 의 url · anonKey 교체 → 다시 배포(supabase/README.md)
